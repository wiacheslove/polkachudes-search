# Поисковый индекс «Полки Чудес»
Каждый час GitHub Actions читает публичный каталог polkachudes.ru (store.tildaapi.com), собирает `docs/core.json` и `docs/thumbs.json` и публикует их через GitHub Pages. Сайт подгружает их при первом фокусе в поле поиска.
- Секретов и персональных данных нет — только то, что уже видно на сайте.
- Если выгрузка подозрительная (меньше 1000 товаров или меньше 80% от прошлой сборки), файлы не обновляются, запуск помечается ошибкой и GitHub присылает письмо.
- Ручной запуск: Actions → build-search-index → Run workflow.
- Откат на сайте: выключить блок «PC search ext» в Tilda.
